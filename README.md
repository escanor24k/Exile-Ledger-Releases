# Exile Ledger – Downloads

**Trade companion & wealth tracker overlay for Path of Exile 1.**

This repository only hosts the official releases of Exile Ledger.

## Download

Open the [latest release](https://github.com/escanor24k/Exile-Ledger-Releases/releases/latest) and pick one of these files:

| File | Description |
|---|---|
| `ExileLedger-Setup.exe` | Installer: start menu & desktop shortcut, optional start with Windows. No admin rights needed. |
| `ExileLedger-Portable.exe` | Portable version: no installation, just run it. |

Once installed, Exile Ledger keeps itself up to date. New versions are offered inside the app.

> **Windows SmartScreen:** the app is not code-signed yet, so Windows may show a warning on first start. Click *More info* → *Run anyway*.

## Requirements

- Windows 10 or 11 (64-bit)
- Path of Exile 1 (English game client), running in *Windowed* or *Windowed Fullscreen* mode
